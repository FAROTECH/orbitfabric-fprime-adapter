# OrbitFabric F Prime Adapter 0.1.0

This is the first stable release of the canonical OrbitFabric adapter for F Prime (F').

The adapter projects explicit OrbitFabric mission-contract entities into FPP declaration fragments while preserving F Prime ownership of component architecture, instances, topology, scheduling and runtime behavior.

## Accepted scope

The `0.1.0` release covers the initial `fpp_contract_projection` operation for:

- telemetry declarations;
- command declarations;
- event declarations;
- telemetry packet specifiers.

The supported target lane is exact and intentionally narrow:

- F Prime `v4.2.2`, commit `8a62e455a90b6d4f498c332d45d65a2a819988d8`;
- FPP `3.2.0`, commit `93f484b7521a8e8894cba25b26e633cc87d8e37a`.

No compatibility range beyond that exact pair is claimed.

## Evidence behind this release

The frozen `0.1.0` source passed the canonical acceptance chain, including:

- Python 3.11 and 3.12 checks;
- wheel packaging and packaged-asset verification;
- managed Adapter Manager lifecycle;
- consumer Reference Example acceptance;
- native F Prime generation, build and dictionary conformance;
- native two-layout architecture-evolution proof;
- GDS closed-loop runtime acceptance;
- provider-neutral release proof.

The two-layout Reference Example demonstrates the central architectural property of this adapter: OrbitFabric mission identity remains stable while explicit downstream F Prime placement changes.

## Deliberate boundaries

This release does not generate an F Prime project or topology and does not infer F Prime architecture from OrbitFabric structure.

The following remain outside the `0.1.0` projection scope:

- data products;
- fault and recovery behavior;
- component or topology generation;
- scheduling and rate groups;
- state machines;
- Scenario execution;
- unproven F Prime or FPP versions.

The F Prime project remains the authority for component instances, topology, wiring, scheduling and runtime implementation. The native F Prime toolchain remains the authority for globally resolved downstream identity.
