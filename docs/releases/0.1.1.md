# OrbitFabric F Prime Adapter 0.1.1

`0.1.1` is a patch release that aligns the Adapter Source Coordinate carried by release metadata with the canonical product identity already documented by the adapter.

## Release identity correction

The canonical Source Coordinate is:

```text
github.com/FAROTECH:orbitfabric/fprime
```

with the structured identity:

```text
authority: github.com/FAROTECH
publisher: orbitfabric
name:      fprime
```

Release bundle generation now derives this identity from the adapter's canonical product constants. CI verifies the same structured identity in generated release material and again in the bytes downloaded from the draft GitHub Release before publication.

This prevents release metadata from drifting independently from the product identity used by the adapter.

## Behavioral compatibility

This patch does not change the F Prime integration behavior or expand the supported surface.

The following remain unchanged:

```text
operation: fpp_contract_projection
OrbitFabric Core baseline: 4377d6656c62aa1dc19a7ed81d2de872b6b22ccd
F Prime: v4.2.2 @ 8a62e455a90b6d4f498c332d45d65a2a819988d8
FPP: 3.2.0 @ 93f484b7521a8e8894cba25b26e633cc87d8e37a
```

Projection Profile semantics, generated FPP declaration fragments, Integration Result behavior, native generate/build acceptance and the GDS closed-loop runtime lane are unchanged from the accepted `0.1.0` product behavior.

## Release lineage

`v0.1.0` remains an immutable historical release and is not modified by this patch.

For exact release resolution against the canonical Adapter Source Coordinate, use `v0.1.1`.
